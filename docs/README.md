# intasend-rs documentation

[Astro Starlight](https://starlight.astro.build), deployed to Cloudflare at
**intasend-rs.pages.dev**.

```sh
pnpm install
pnpm dev          # http://localhost:4321
pnpm build        # → dist/
pnpm deploy       # build, then wrangler deploy
```

## Layout

```
src/content/docs/     one directory per API area
src/content.config.ts declares the `docs` collection — without it the build
                      silently produces a single 404 page
astro.config.mjs      sidebar, written out rather than autogenerated
wrangler.jsonc        Cloudflare target
```

The sidebar is explicit on purpose. Autogeneration sorts alphabetically, which
puts "Hello, World!" before "Installation" and scrambles the payouts sequence —
these pages have a reading order, inherited from the mdBook `SUMMARY.md` they
came from.

## Examples are the source of truth

Each API overview page embeds the whole of the matching file from
`examples/src/bin/`. Those are workspace members, so `cargo build` and `cargo
clippy` compile them: when the SDK changes underneath, CI fails rather than the
documentation going quietly stale.

Prefer extending an example and embedding it over writing a snippet inline. A
snippet nobody compiles is a snippet that stops being true.
